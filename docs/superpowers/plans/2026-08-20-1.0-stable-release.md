# 1.0.0 Stable Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 0.3.x 至 0.6.x 能力完成并经过业务验证后，冻结公共 API、内容协议和安全边界，发布可长期维护的 1.0.0。

**Architecture:** 1.0 不新增大范围业务功能，主要完成契约冻结、兼容矩阵、Migration Guide、测试矩阵、性能基线、包产物检查和发布流程。Variables、AI、Email、Storefront 等能力不阻塞本版本。

**Tech Stack:** TypeScript, React 18, Tiptap 3, Next.js 15, Vitest, pnpm, npm registry.

---

## 分支和前置条件

```bash
git switch main
git pull --ff-only
git switch -c codex/1.0-stable-release
```

开始前必须确认：

- `0.3.x`、`0.4.x`、`0.5.x` 和 `0.6.x` 均已合并到 `main`；
- 所有阶段的合并门禁均有记录；
- 没有未解决的 P1 数据丢失、安全或公共 API 兼容问题；
- 当前工作区没有与发布无关的未提交代码。

- [ ] **Step 1：列出稳定导出**

- [ ] **Step 2：确认旧 API 兼容层**

- [ ] **Step 4：建立兼容矩阵**

矩阵至少包含包版本、React、Tiptap、Polaris、Node.js、Schema Version、Channel 和 Migration 支持范围。
