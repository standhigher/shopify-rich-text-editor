# 0.5.x Shopify Native Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在完成 Shopify 能力预研后，引入 ResourceProvider 和 Product、Collection、Variant 资源引用，并保证资源数据不会污染最终 HTML。

**Architecture:** Provider 负责外部资源选择，Extension 负责编辑器中的 Resource Node，Server Adapter 负责校验和 Shopify HTML 输出。编辑器不直接依赖 App Bridge 或 Shopify Admin API；业务应用通过 Provider 注入选择和解析能力。

**Tech Stack:** TypeScript, React 18, Tiptap 3, Shopify Polaris, Shopify App Bridge integration supplied by the host app, Vitest, Next.js demo.
